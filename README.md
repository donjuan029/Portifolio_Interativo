4. **Software & Cloud Architecture Explorer**: System designs and trade-off analyses for Enterprise RAG, Modular Monoliths, Multi-Agent Swarms, and Zero-Trust Cloud perimeters.

## 🛠️ Getting Started

### Prerequisites
- Node.js `v18+` or `v24+`
- npm `v9+` or `v11+`

### Installation
```bash
# Clone repository
git clone https://github.com/donjuan029/portfolio.git
cd portfolio

# Install dependencies
npm install
```

### Running Locally
```bash
# Start development server with HMR
npm run dev

# Run production build and preview
npm run build
npm run preview
```

## 🚀 Deployment

### Deploy to Vercel / Netlify
This project builds standard static client assets into the `dist/` directory:
1. Connect your GitHub repository to [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
2. Set build command: `npm run build`
3. Set output directory: `dist`
4. Deploy!

### Deploy to GitHub Pages
Add the `base` attribute in `vite.config.ts` if deploying to a subpath:
```ts
export default defineConfig({
  base: '/portfolio/', // replace with your repo name
  plugins: [react()],
})
```
