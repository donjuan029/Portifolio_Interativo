# 🏗️ Engineering Philosophy

The portfolio is structured around a few principles:

### Evidence over claims

Technologies and capabilities are presented through projects, architectural diagrams, experiments, implementations and technical documentation whenever possible.

### Architecture before abstraction

Important technical decisions are documented through system designs, trade-offs, constraints and architectural reasoning.

### Security by design

Security is treated as a foundational engineering concern rather than an isolated feature.

### AI with deterministic foundations

AI components are designed with appropriate boundaries between probabilistic models and deterministic software logic.

### Developer experience matters

Navigation, search, keyboard shortcuts, documentation and discoverability are treated as part of the engineering experience.

# 🤖 Featured Case Study — FinAI Assistant

One of the flagship projects presented in the portfolio is **FinAI Assistant**, a multimodal financial intelligence application.

The architecture separates **semantic interpretation** from **deterministic computation**.

```text
                    ┌─────────────────┐
                    │      User       │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ Voice / Text    │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ Whisper / ASR   │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │      LLM        │
                    │ Semantic Layer  │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ Structured Data │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ Pandas / Python │
                    │ Deterministic   │
                    │ Computation     │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │    Response     │
                    └─────────────────┘
```

### Architectural principle

The LLM is responsible for **understanding the user's intent**.

Deterministic software is responsible for **calculations and numerical transformations**.

This separation reduces the risk of relying on probabilistic generation for operations where deterministic computation is required.

# 🚀 Getting Started

## Prerequisites

* Node.js `18+`
* npm `9+`

Recommended:

* Node.js `24+`
* npm `11+`

## Installation

```bash
git clone https://github.com/donjuan029/portfolio.git

cd portfolio

npm install
```

## Development

Start the development server:

```bash
npm run dev
```

The application will be available through the local Vite development server.

## Production Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```

# ☁️ Deployment

## Vercel / Netlify

Recommended configuration:

```text
Build Command: npm run build
Output Directory: dist
```

## GitHub Pages

When deploying under a repository subpath, configure the Vite base path:

```ts
export default defineConfig({
  base: '/portfolio/',
  plugins: [react()],
})
```

Replace `/portfolio/` with the appropriate repository path.

# 🔐 Security Considerations

No credentials, API keys or private configuration should be committed to the repository.

Use environment variables for secrets:

```env
VITE_API_KEY=your_key_here
```

Never commit:

```text
.env
.env.local
credentials
private keys
access tokens
service account files
```

Ensure sensitive files are included in `.gitignore`.
